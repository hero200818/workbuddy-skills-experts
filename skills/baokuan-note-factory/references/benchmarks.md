# 诊断基准表

> 标注说明：「官方」= 平台后台直接给出的数据；「经验基准」= 运营经验判断，非平台口径；「定性」= 需结合账号具体情况解读。

## 核心指标基准（读书/知识类新号，粉丝 <1000）

| 指标 | 计算式 | 危险线 | 健康线 | 类型 |
|---|---|---|---|---|
| 封面点击率 | 后台直读 | <3% | 5%–8%+ | 经验基准 |
| 曝光→观看转化 | views/impr | <15% | 20%–30% | 经验基准 |
| 互动率（对曝光） | (赞+藏+评)/impr | <1.5% | 3%–5% | 经验基准 |
| 互动率（对观看） | (赞+藏+评)/views | <3% | 5%–10% | 经验基准 |
| 每千曝光涨粉 | follows/impr×1000 | <1 | 3–5+ | 经验基准 |
| 收藏/点赞比 | saves/likes | — | >1 工具型；≈1 共鸣型 | 定性 |
| 零评论笔记占比 | — | >70% | <30% | 经验基准 |
| 单篇均曝光 | — | <100（初级池都进不去） | 200–500 起步正常 | 定性 |

## 流量池档位（定性）

- 0–200：完全冷启动/疑似限流
- 200–500：初级池（多数新号常态，互动率决定升级）
- 1000–5000：二级池
- 1w+：热门池

## 平台官方诊断雷达（账号概览页，优先采信）

观看数/互动数/涨粉数/发布数/主页访客各维度"超过同类%"：
- 全部 ≥80% 且只有涨粉低 → 转化断裂型：主攻关注理由（结尾引导/合集/人设统一）
- 观看低 + 曝光低 → 冷启动失败型：主攻封面点击率+完播
- 曝光高 + 观看低 → 标题封面错配型：人群与选题不匹配

## 观看来源结构判型（APP 账号概览）

| 结构 | 账号类型 | 主攻指标 |
|---|---|---|
| 首页推荐 >70% | 内容推荐型 | 点击率、互动率 |
| 搜索 >25% | 搜索型（书名/关键词资产） | 标题含热词、SEO 型选题 |
| 视频推荐 >50% | 视频形态号 | 完播率、前3秒 |
| 关注页 >15% | 粉丝粘性强 | 维持，防断更 |
| 个人主页高 | 转化链健康 | 放大 |

## 常见病症 → 处方速查

| 症状 | 根因 | 处方 |
|---|---|---|
| 曝光稳定但不涨粉 | 无关注理由 | 结尾固定引导语+合集+人设统一 |
| 模板标题点击率均值低 | 无差异化 | 痛点/悬念+数字+人群指向改写 |
| 完播率环比暴跌 | 前3秒流失 | 悬念句开场，压时长至60–90秒 |
| 老粉零互动 | 死粉盘 | 回访忠实粉+选择题式笔记 |
| 新笔记差旧笔记长尾好 | 方向跑偏 | 复盘旧爆款共性，回归主线 |
| 发布时间错过峰值 | 排期错位 | 峰值前1–2小时定时 |

## 复盘判定（发布包标准）

- 主线确认：A 线平均涨粉 > B 线 → A 线占比提至 ≥70%
- 标题法生效：新笔记点击率均值 ≥5% → 旧模板永久弃用
- 完播率 <15% → 视频 ≤60 秒，悬念句上封面
- 单篇评论 ≥10 → 评论区问题即下一篇选题
