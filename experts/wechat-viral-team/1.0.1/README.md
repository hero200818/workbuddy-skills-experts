# 微信公众号爆文超级运营专家团

从一条热搜到一篇能直接发的稿子，六个岗接力跑完，每一步都有硬门槛。

## 类型

专家团（team）· 1 位主理人 + 6 位团员 · 行业分类：内容创作（06-ContentCreative）

## 成员

| 名字 | 职业 | 负责什么 | 什么时候找它 |
|---|---|---|---|
| **闻风起** | 爆款操盘主编（主理人） | 选题决断、SOP 编排、终审汇编、门槛把关 | 任何综合性任务，它会自动派人 |
| **甄有亮** | 热点选题猎手 | 八平台热榜抓取、红线剔除、去重、四维评分 | "今天写什么""这个选题能不能写" |
| **柳成章** | 爆款长文撰稿 | 1500–2000 字成稿、去 AI 味、结构骨架 | "写成文""这篇像 AI 写的" |
| **邵一眼** | 标题与钩子打磨师 | 30 字内标题、开头六种钩子、结尾引评论 | "起 3 个标题""开头留不住人" |
| **严守正** | 合规与事实核查官 | 红线判断、事实可核性、标题禁区、医疗金融合规 | "这篇能不能发""哪句必须改" |
| **柯一帧** | 配图与视觉设计 | 配图方案、ImageGen 提示词、去水印、两档体积 | "配几张图""封面怎么设计" |
| **章有数** | 数据复盘增长师 | 台账口径、三看归因、单变量建议 | "这篇为什么不行""下一篇改什么" |

## 四套工作流

| 工作流 | 触发 | 编排 |
|---|---|---|
| **W1 从零出一篇** | "写一篇 XX""我要能直接发的稿子" | 选题 → 并行（撰稿 + 配图）→ 标题 → 合规 → 主编汇编落盘 |
| **W2 老稿救活** | "这篇改改""发不出去" | 并行（合规 + 标题）→ 撰稿重写 → 主编汇编 |
| **W3 数据诊断** | "数据不好""为什么没火" | 复盘归因 → 标题/开头修补 → 结论一句 |
| **W4 只挑选题** | "今天写什么" | 选题岗单发，不拉全队 |

单维度问题走直调：起标题找邵一眼，查合规找严守正，看数据找章有数。

## 内置的两个技能

### `gzh-viral-ops` — 流水线工具（16 条命令）

```bash
python scripts/gzh.py status                    # 全项目状态一眼看清
python scripts/gzh.py pick --top 3              # 按分数挑下一篇
python scripts/gzh.py brief --no 21             # 生成写作任务书
python scripts/gzh.py score --no 21 --heat 7 --resonance 9 --tension 7 --risk 9 --save
python scripts/gzh.py lint --md 主稿.md         # 结构与红线自检（15 条规则）
python scripts/gzh.py assets --dir 配图 --check # 配图双档体积核查
python scripts/gzh.py preflight --slug 选题3    # 发布前总闸
python scripts/gzh.py selftest                  # 自测 29 例
```

含三份方法论：合规基线、技术踩坑手册、四维评分档位表，另加配图规范与数据复盘口径。

### `title-hook-lab` — 标题工坊

```bash
python scripts/title_score.py "候选一" "候选二" "候选三"
python scripts/title_score.py --selftest
```

五维打分（长度 15% / 具体性 30% / 钩子 30% / 情绪 15% / 风险 10%），
判定 ≥80 优 / 70–79 可用 / 55–69 偏弱 / <55 不宜。另含三套标题公式、六种开头钩子、三种结尾收法。

## 怎么用

第一次对话它会问"今天该写哪篇"，并给出 3 个候选。也可以直接说：

- `把「停车按分钟计费」写成一篇能直接发的公众号爆文`
- `这篇数据不行，帮我查清问题在标题、开头还是结尾`
- `这两个标题哪个好，为什么`

它会在你的项目目录里跑脚本（认 `config.json`）。新号第一次用，先让它用
`gzh-viral-ops` 的 `templates/project/` 初始化一个项目目录。

## 硬门槛

| 项 | 阈值 |
|---|---|
| 标题 | 言序/草稿箱 ≤30 字（微信 ≤64） |
| 摘要 | ≤120 字 |
| 封面 | ≤2MB |
| 正文图 | ≤1MB |
| 配图水印 | 必须裁掉（底边 72px） |
| 结构自检 | error 0 才发 |

## 头像

`avatars/` 下有 8 张：团队 1 张 + 7 位成员各 1 张。均为 512×512 PNG、≤500KB。
要换风格，替换同名文件即可。
