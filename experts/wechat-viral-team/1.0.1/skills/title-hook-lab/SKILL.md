# 标题与开头工坊

一篇公众号的生死在前 3 秒：标题决定点开率，开头决定完读率。这两个环节**不能靠感觉**，
因为感觉无法复用，也无法交给别人复核。

## 什么时候用它

| 场景 | 用法 |
|---|---|
| 有一条标题，想知道能不能发 | 跑 `title_score.py`，看字数与风险两项 |
| 有 3–5 条候选，不知道选哪条 | 一次传全部，看横向排序 |
| 标题写完总觉得"差点意思" | 看它给的最弱维度建议，缺哪补哪 |
| 正文写完了，开头留不住人 | 用下文「六种开头钩子」重写第一段 |
| 结尾没人评论 | 用「三种结尾收法」，尤其第一种 |

## 评测脚本

```bash
python scripts/title_score.py "候选标题一" "候选标题二" "候选标题三"
python scripts/title_score.py --file 候选.txt        # 每行一条
python scripts/title_score.py --channel wechat "标题" # 微信原生编辑器口径 ≤64
python scripts/title_score.py --json "标题"           # 机器可读
python scripts/title_score.py --selftest              # 改过词表后必跑
```

五维权重与含义：

| 维度 | 权重 | 看什么 | 为什么重要 |
|---|---|---|---|
| 长度 | 15% | 16 字到通道上限之间最佳 | 言序硬上限 30 字；微信超 30 字在信息流被截断，后半句钩子白写 |
| 具体性 | 30% | 数字、机构、地名、具象物 | "有人被多收了钱"没人信；"停车 64 分钟按 2 小时收费"才有画面 |
| 钩子 | 30% | 数字/身份/反差/疑问/悬念/利益 六类命中几类 | 单一钩子会被同类标题淹没，三类以上才有立体感 |
| 情绪 | 15% | 委屈、不服、荒诞、温情等词 | 读者转发的是情绪，不是信息 |
| 风险 | 10% | 诱导词、绝对化、标点滥用 | 标题党不进推荐池，还可能扣权 |

判定：**≥80 优 / 70–79 可用 / 55–69 偏弱 / <55 不宜**。

> **分数是结构诊断，不是文学判决。** 它衡量的是"具体不具体、钩子够不够、会不会被限流"，
> 不衡量观点锋不锋利。一条 45 分但观点极硬的标题，可以保留——但请补一个具体场景进去，
> 通常能直接拉到 70 分以上。最终发哪条，人说了算。

## 三套标题公式

### 公式 A：身份 × 处境 × 未轮到（共鸣型，适用年龄/职场/代际）

```
{年龄或身份}怕{具体压力}，{另一身份}怕{另一压力}：{一句态度}
```
例：`35岁怕优化，60岁怕负担：你笑"老登"的底气，还没轮到你`（29 字 / 82.7 分）

结构要点：两个年龄形成对照 → 读者自动对号入座 → 冒号后一句是立场，不是总结。

### 公式 B：数字 × 反常 × 归属（事实型，适用消费/收费/规则）

```
{具体数字}的{事}，{反常做法}，{谁}却{结果}
```
例：`停车64分钟按2小时收费，多地改成按分钟计费，多收的钱能退吗`（30 字内）

结构要点：数字必须真实可查；"反常做法"要有权威来源；结尾留一个读者能回答的问题。

### 公式 C：提问 × 常识 × 反打（观点型，适用社会话题）

```
人人都在{某共识}，可{反例}，{反问}
```
例：`人人都会变老，为什么还要嘲笑"老登"`

结构要点：先承认共识（降低对抗），再给反例（制造不适），最后反问（把话筒递给读者）。
**这条路的分数通常只有 45–60**，因为不带具体数字；它的杀伤力在观点，不在结构。
用公式 C 时务必在正文前三段补一个具体场景，把"观点"落成"事"。

## 标题数字的三道闸（人工，评分脚本抓不到）

评分只数"有没有数字"，**不管这个数字站不站得住、咬不咬得上**。以下三道必须人工过，硬度和 30 字上限同级。

**① 出处闸：数字必须来自一手文件，不能来自转述或推算。**

- 反例（2026-11 选题53）：标题写「公司要每 3 小时看手机」。正文里公司教学文件写的是「休息日每日定时查看 **3 次**」；「每隔 3 小时」是组长当晚在群里口头提的，原话还带「尽量」。公司一句"我们从没这么要求"，标题当场成靶子。
- 判据：能不能指着某份文件或某个官方发布说"这个数在这儿"？指不出来就换掉。

**② 验算闸：两个以上数字必须同维度，且读者算完要站在我们这边。**

- 反例：「每天 3 次 / 她 5 小时没看」→ 读者一算"3 次可以排在 5 小时之外"，**算出来的结论站对方**，标题等于替对方写好了辩词。
- 反例：「每 3 小时 / 她 5 小时没看」→ 读者算 5>3 站我们，但出处不实（见①）。
- 闭合写法：「每天 3 次 / 她看了零次」→ 0<3 站我们，逻辑闭合，但把"5 小时"这个人味换掉了，点开率会掉。
- 判据：把两个数字代进读者脑子算一遍，结果必须指向"对方有问题"。

**③ 余量闸：悬念要大于读者的计算能力。**
能被一步算完的悬念不是悬念，是送分题。

一句话：**数字进标题前先问两件事——这个数站得住吗，读者算完站谁那边。** 站不住、或站对方，宁可少一个数字。

## 六种开头钩子（第一段只能选一种，别混）

| 钩子 | 写法 | 例句 |
|---|---|---|
| **场景直击** | 一个具体到能看见的画面 | `地铁上两个小姑娘笑得很响，我顺着看过去，笑的是一个拎着菜的老人。` |
| **数字反常** | 一个与常识相反的数 | `64 分钟，收 2 小时的钱。这不是段子，是很多停车场的计费规则。` |
| **身份代入** | 直接喊出读者是谁 | `如果你今年 35 岁，这句话你大概听过：要优化，先优化年纪大的。` |
| **共识反打** | 先认同，再翻面 | `谁都想年轻。我也想过。可这事有个前提——你得一直年轻下去。` |
| **细节提问** | 用一个细节逼出思考 | `为什么同样是老，六十岁叫"老登"，七十岁叫"老人家"？` |
| **结果前置** | 先给结局，再讲过程 | `他把车开出停车场时才发现，停 64 分钟，按 2 小时收费。` |

**禁止的开头**：`随着社会的发展`、`在当今时代`、`近年来`、`不知道你有没有发现`、
`今天我想和大家聊聊`。这五种开头等于告诉读者"下面可以不看"。

## 三种结尾收法

1. **两问收尾**（引评论最有效）：一个问句问自己，一个问句问读者。
   ```
   我今年四十，也笑过别人。轮到我时，谁来笑我？
   你身边有没有这样一位"老登"？你上一次笑他，是什么时候？
   ```
2. **动作收尾**：给一件今天就能做的小事，比讲道理有力。
   `下次再想笑的时候，先看一眼他的手。`
3. **留白收尾**：一句短句单独成段，不加解释。
   `我们都会老。这不是安慰，是通知。`

## 标题六条禁令

1. 不用"震惊/速看/必看/删前/疯传"等诱导词
2. 不用"最/第一/唯一/百分百"等绝对化表述
3. 不叠感叹号与问号（`！！` `？？`）
4. 不用"刚刚/紧急/突发"制造虚假时效
5. 不在标题里写未经证实的具体指控（人名 + 罪名）
6. 不承诺疗效、收益、必然结果

## 交付格式（给主理人的回传）

```
【标题候选】
1. {标题}   {字数} 字  {分数} 分  {判定}
2. ...
3. ...

【主推】{第几条}，理由：{一句话}
【开头钩子】{类型} —— {实际写出的第一段}
【结尾收法】{两问/动作/留白} —— {实际写出的结尾}
【弃用说明】{为什么另外几条不行}
```

## 自检

改过任何词表或权重，必须跑一次：

```bash
python scripts/title_score.py --selftest    # 应为 5 passed / 0 failed
```
