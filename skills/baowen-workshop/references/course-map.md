# 头条创作训练营课程地图（2026-09 后台实采）

官方训练营共约308门课，分四大板块。下面标注与"读书悦己"（普通人情感故事线）相关的核心课及要点。

## 一、新手入门（49门）—— 必看

| 课程 | 学到什么 |
|---|---|
| 5分钟了解今日头条内容推荐机制 | 内容进"阅读队列"→按阅读时长/完读率/评论意愿决定放量 |
| 官方解读如何更好获得头条推荐 | 初始流量池小步测试，数据好才进大池 |
| 内容审核红线 / 避雷小课堂 | **红线**：虚假内容、违规推广、标题党、旧闻新发——我们坚决不碰 |
| 什么是原创图文 | 原创才拿首发补贴；洗稿/拼凑会被降权 |
| 产品经理讲正确的互动"姿势" | 互动要自然，不互赞互粉（与我们红线一致） |

## 二、账号运营（62门）—— 写作主课

| 课程 | 要点 |
|---|---|
| 手把手教你写大家都爱看的优质爆款 | 选题>标题>结构：选题决定推不推、标题决定点不点、结构决定完读完 |
| 4步获得更多推荐 | 开头留钩子、中间有信息增量、结尾引导评论 |
| 标题、开头和结尾的写法 | 开头57字定生死；结尾用选择题式互动 |
| 创作微头条的几个小技巧（6.5万看过） | 短平快：人设标签开头→情绪点→细节→观点→提问 |
| 发布微头条的三个小技巧（8.1万看过） | 垂直标签、配图相关、发布时间固定 |
| 写出有信息增量的内容 | 不写正确的废话，每条要给读者一个"原来如此"或"我也这样" |
| 垂直度高有什么好处 | 一个赛道打透，算法才能精准打标签 |

## 四、变现攻略（57门）

- 微头条收益大揭秘（135.8万看过）：阅读量≠收益，有效获利阅读（停留>30秒+滚动>70%）才算
- 图文广告收益影响因素：完读、互动、内容质量
- 首发动态1~5倍分成，质量定倍数

## 对我们SOP的硬性约束（从课程归纳）

1. 每条内容必须有"信息增量"：具体数字/独家细节/真实情绪，不写正确的废话。
2. 垂直打透普通人故事赛道，不蹭无关热点。
3. 四不碰：虚假、标题党、旧闻新发、违规推广。
4. 互动自然，不刷量。
5. 原创首发，吃动态分成。
