# MD2Card 是什么？

MD2card 可以将 Markdown 文档转换为精美的知识卡片，支持多种风格。

==Markdown 基础语法==

## 1. 标题：让你的内容层次分明

用 `#` 号来创建标题。标题从 `#` 开始，`#` 的数量表示标题的级别。

```markdown
# 一级标题
## 二级标题
### 三级标题
```

## 2. 列表：让信息一目了然

- 无序列表使用 `-` 或 `*`
- 有序列表使用 `1. 2. 3.`
- 支持嵌套列表

## 3. 代码：展示技术细节

行内代码用 `` ` `` 包裹，比如 `print("hello")`。

代码块用三个反引号包裹：

```python
def hello():
    print("Hello, MD2Card!")
```
