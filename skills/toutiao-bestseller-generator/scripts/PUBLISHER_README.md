# 头条号文章自动发布工具 - 使用说明

## 一、功能介绍

自动读取本地生成的文章（Markdown + 图片），登录头条号后台，自动填写标题、正文、上传封面和配图，保存为草稿或直接发布。

**两种模式：**
- 单篇发布：指定一个文章文件夹
- 批量发布：指定作品根目录，自动发布所有文章

## 二、环境准备

### 2.1 安装 Python

确保已安装 Python 3.8+。

### 2.2 安装依赖

```bash
cd toutiao_auto_tool
pip install playwright
playwright install chromium
```

> 注意：`playwright install chromium` 会下载浏览器内核，约150MB，请耐心等待。

## 三、使用步骤

### 第一步：登录头条号（首次必做）

```bash
python toutiao_publisher.py --login
```

运行后会自动打开浏览器，跳转到头条号登录页：
1. 在浏览器中用手机扫码或账号密码登录
2. 登录成功后，回到命令行窗口
3. 按回车键确认
4. 登录态会自动保存到 `toutiao_cookies.json`

> 登录态有效期约7-30天，失效后重新运行 `--login` 即可。

### 第二步：发布文章

#### 方式A：发布单篇文章

```bash
python toutiao_publisher.py --folder ./output/围城_20260819/01_方鸿渐/
```

脚本会：
1. 自动读取该文件夹下的 `.md` 文章和 `.png` 图片
2. 打开头条号发布页面
3. 自动填写标题和正文
4. 上传第一张图作为封面
5. 其余图片插入正文
6. **默认保存为草稿**（你可以登录后台检查后手动发布）

#### 方式B：批量发布所有文章

```bash
python toutiao_publisher.py --batch ./output/围城_20260819/
```

脚本会依次处理该目录下所有以数字开头的文章文件夹。

#### 方式C：直接发布（不保存草稿）

在以上命令后加 `--publish` 参数：

```bash
python toutiao_publisher.py --folder ./output/围城_20260819/01_方鸿渐/ --publish
```

> ⚠️ 谨慎使用！直接发布会立即上线，建议先用默认草稿模式检查。

### 第三步：检查和发布

1. 登录头条号后台：https://mp.toutiao.com/
2. 进入「内容管理」→「草稿箱」
3. 打开文章检查排版、图片、标题
4. 确认无误后点击「发布」

## 四、命令参数说明

| 参数 | 说明 |
|------|------|
| `--login` | 登录头条号并保存登录态 |
| `--folder <路径>` | 发布单篇文章（指定文章文件夹） |
| `--batch <路径>` | 批量发布（指定作品根目录） |
| `--publish` | 直接发布（默认仅保存草稿） |
| `--headless` | 无头模式（不显示浏览器窗口） |

## 五、文件夹结构要求

脚本期望的文章文件夹结构：

```
01_方鸿渐一个好人为什么过不好一生/
├── 01_方鸿渐一个好人为什么过不好一生.md      ← 文章正文（必填）
├── 01_方鸿渐一个好人为什么过不好一生_1.png   ← 第一张作为封面
├── 01_方鸿渐一个好人为什么过不好一生_2.png   ← 内容配图
└── ...
```

- `.md` 文件：文章正文（标题用 `# ` 标记）
- `_1.png`：封面图
- `_2.png` 及以后：正文配图（按顺序插入）

## 六、常见问题

**Q: 提示 "未找到登录态"？**
A: 首次使用必须先运行 `python toutiao_publisher.py --login`。

**Q: 登录态失效了怎么办？**
A: 重新运行 `--login` 即可。

**Q: 页面元素找不到/填写失败？**
A: 头条号页面可能更新，脚本中的CSS选择器需要调整。可以：
   1. 检查 `screenshots/` 目录下的错误截图
   2. 手动在浏览器中完成发布
   3. 反馈问题，更新脚本选择器

**Q: 图片没有上传成功？**
A: 头条号的图片上传接口可能变化，可以手动在编辑器中上传图片。

**Q: 可以完全无人值守吗？**
A: 建议首次使用时观察浏览器操作，确认流程正常后再用 `--headless` 无头模式批量运行。

**Q: 发布失败了怎么办？**
A: 脚本会在 `screenshots/` 目录保存错误截图，根据截图判断问题。常见原因：
   - 登录态失效 → 重新登录
   - 标题含敏感词 → 修改标题
   - 正文格式问题 → 检查Markdown内容
   - 网络问题 → 重试

## 七、安全提示

1. **登录态文件 `toutiao_cookies.json` 包含你的账号信息，请勿分享给他人**
2. 建议先用草稿模式，检查无误后再手动发布
3. 批量发布时注意头条号的发布频率限制（一般每天不超过50篇）
4. 如账号出现异常，请立即停止脚本并修改密码

## 八、与文章生成器配合使用

完整工作流：

```bash
# 1. 生成文章（含图片）
python toutiao_generator.py "围城"

# 2. 登录头条号（首次）
python toutiao_publisher.py --login

# 3. 批量发布为草稿
python toutiao_publisher.py --batch ./output/围城_20260819/

# 4. 登录头条号后台检查并发布
```

## 九、技术说明

- 基于 Playwright 自动化框架
- 使用 Chromium 浏览器内核
- 登录态通过 Cookies 持久化保存
- 支持单篇和批量两种模式
- 自动截图保存预览和错误信息
