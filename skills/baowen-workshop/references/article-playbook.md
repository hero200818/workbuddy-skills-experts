# 爆款长文写作规范（周哥人设）

长文与微头条共用同一个人设和选题池：**微头条是探路，跑出来的爆款选题扩写成1200-1500字长文，声明首发拿动态分成**。不另起历史/读书方向。

## 平台机制（2025-2026 调研结论，写稿必须对齐）

- **分发流程（官方口径）**：新内容发出→系统找潜在读者进"阅读队列"→按**阅读时长、阅读完成率、评论意愿**决定是否继续分发；深度优质图文有冷启动流量池扶持。
- **有效获利阅读判定**：用户停留>30秒 且 滚动深度>70%；完读率<5%直接被算法降权。800字左右实用/故事内容收益最高。
- **初始流量池约5000曝光**，按点击率/完读率/互动率决定放量；标题点击率从3%提到8%，推荐量可差12倍。
- **完读率>65%，次轮推荐约3倍放大**；标题关键词匹配不准，首轮推荐可差30倍。
- **首发分成**：2025年8月起取消固定3倍，改为**动态1~5倍补贴，与内容质量强挂钩**——信息稀缺、时效独家、观点独特的才拿得到高倍；空洞水文拿不到补贴。
- **标题点击率**健康区间 12%-15%，超过就是标题党风险。
- **头条主力受众 40-60 岁**：周哥人设虽是35岁，但选题要往这个人群的共鸣池靠——中年危机、人情世故、夫妻关系、房子车子、子女教育、攒钱省钱。
- **微头条前三行（约57字）定生死**：信息流只展示前两行半，第一句必须是悬念留白或场景代入，不能平淡开头。
- **文末用"选择题"提问**（"你是A情况还是B情况？"），评论量约提升3倍，直接拉互动权重。
- **排版**：每段≤100字（手机屏2-3行），可加小标题；文中插1个1-2分钟相关短视频，平均阅读时长+50%。
- **标签**：兴趣矩阵3.0按语义识别，三级标签——1个核心标签定人群 + 2个垂直标签，不蹭无关热点。

## 选题来源

1. 本周微头条中赞最高的那条（首选，已验证有共鸣）。
2. 本周评论区用户问得最多的问题（如"房租多少""怎么攒钱"）。
3. 每月固定节点：发工资日（10号前后）、交房租日、逢年过节随礼。
4. 选题三要素自查：戳痛点 + 给利益点（具体数字/方法）+ 情绪共鸣，三者至少占二。

## 标题公式

先读 `references/title-and-hook-library.md`（6种标题公式、7个心理缺口、3种钩子）。标题二选一给，数字+身份+冲突/悬念（目标点击率12-15%，不做标题党）：
- 《35岁程序员发工资到账14200，扣完房租我在楼下站了十分钟》
- 《北漂第10年，我算了笔账：月薪18k为什么还是存不下钱》

## 正文结构（1200-1500字，冲突-转折-启发三段式）

```
开头前57字（信息流只显示前三行，生死线）：直接抛场景/数字/反差或悬念留白，禁用"今天给大家聊聊"
   例：今天10号，工资到账短信弹出来：14200.36。我盯着屏幕看了三遍。
中间（冲突-转折，每节200-300字）：
   - 算账/冲突：房租3800水电，给家里转2000，女友生日准备买礼物
   - 细节：保留对话原话、金额、地点（公司楼下沙县/地铁10号线）
   - 转折：闪回一句对比（刚毕业4800 vs 现在14200）
收尾（启发，100字）：一句自嘲式感慨，不卖惨不鸡汤
最后：选择题式开放式提问（给A/B两个选项让读者站队），评论量约3倍
   例："你们发工资第一件事是先转家里，还是先还花呗？"
```

## 写作纪律

- 段落短：每段≤100字、2-3行；小标题只在长文里用1-2个，不堆砌。
- 具体 > 抽象：写"沙县拌面加蛋14块"，不写"消费很高"。
- 不编极端惨事：不写大病、被裁跳楼，写普通35岁的真实拮据。
- 标签3个（1核心+2垂直白名单）；配图3-4张生活化；**必勾首发**。
- 文中建议提一句可配1段相关1分钟短视频（作者自行拍摄）。

## 与微头条的配合

- 长文发布后，当晚发1条微头条摘录（"今天算了笔账，写长文里了"），挂长文引流。
- 长文发布后1小时内回完评论——评论/完读数据直接决定次轮推荐量级和分成倍数。
