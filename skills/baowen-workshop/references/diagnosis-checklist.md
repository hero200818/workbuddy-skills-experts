# 账号诊断清单

逐项检查，能回答就给结论，不能就标"未见数据"。

## 1. 基础盘

- 粉丝量、获赞量、关注数；赞粉比（获赞/粉丝）——高赞粉比说明靠爆款而非日常留存。
- 简介与头像传达的定位是什么？
- 有无领域认证？
- 内容可见时间跨度：最早一条到最新一条隔多久？

## 2. 内容结构（分体裁统计）

| 体裁 | 条数 | 集中发布日期 | 平均阅读/播放/赞 | 中位数 | 最高单条 |
|---|---|---|---|---|---|
| 文章 | | | | | |
| 视频 | | | | | |
| 微头条 | | | | | |

判断：哪个体裁是真实流量主力？（通常微头条赞/评论远高于文章阅读和视频播放。）

## 3. 定位一致性

- 简介宣称的方向 vs 近期实际内容方向是否一致？不一致即为"定位漂移"。
- 账号名与内容是否匹配？
- 有没有互相矛盾的内容线同时更新（如读书号同时更汽车合集）？

## 4. 低质/批量生产信号（出现即指出）

- 同一天集中发布多篇文章/多条视频。
- 文章配图与主题无关（历史文配外国街拍、写字楼图库图）。
- 微头条单条挂 15-30 个话题标签，其中大量与正文无关（蹭热点、明星动漫、时政标签）。
- 视频封面模板化、AI 插画，标签与内容无关。
- 标题全是同一套路（"XXX为什么YYY？""读懂这N个细节"）。

## 5. 人设与内容质量

- 微头条是否有固定人设（年龄、职业、城市、收入细节）？人设细节是否前后一致？
- 叙事模板是什么？（如：第一人称故事→细节→感慨→提问互动）
- 情绪基调：卖惨 / 共鸣 / 治愈 / 吐槽？

## 6. 粉丝匹配度

- 粉丝量 vs 文章平均阅读的巨大差距 = 粉丝不消费长内容、泛粉沉睡。
- 关注数为个位数、评论区不互动 = 账号活跃度低，互动系数被压。

## 7. 风险

- 蹭无关热点标签 → 限流风险
- 简介误导 → 关注转化率低
- 虚构卖惨人设 → 争议风险
- 只靠单一体裁 → 结构脆弱

## 8. 报告输出格式

结论先行（一句话定性）→ 账号概况表 → 分体裁内容盘点 → 运营特征判断 → ECharts 可视化（流量对比/主题占比）→ 风险点 → 数据局限说明。
