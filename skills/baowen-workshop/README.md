# 爆文工坊 · BaoWen Workshop

> 头条号（今日头条创作者）爆款内容自动化生产系统
> 从账号诊断 → 人设定位 → 每日出稿 → 数据复盘 → 评论运营，全链路闭环

---

## 这是什么

一套经过真实账号（读书悦己，4.7万粉）跑通的头条号运营方法论 + AI 工作流。
核心是"老周/周哥"人设：35岁北漂程序员，用真实生活切片（工资、房租、随礼、外卖）打公域推荐流量。

**已验证爆款参数（来自真实后台数据）：**
- 微头条 100-150字（106字最爆），无标题，单一切片
- 必须有：一句对话 + 一个身体反应 + 扎心结尾 + 开放式提问
- 长文 1200-1500字，数字+身份+冲突标题，吃首发3倍分成
- 固定晚 20:00 发，发后 20-22 点是黄金互动窗

## 快速开始

### 1. 诊断一个现有头条号
把主页链接（toutiao.com/c/user/token/...）丢给 AI，让它按 SKILL.md 走：
采集公开数据 → 按 diagnosis-checklist 逐项诊断 → 输出激活执行方案（Markdown）。

### 2. 搭建自动化双循环
- **每日 19:35**：按星期栏目生成当日微头条成稿（存草稿，用户20:00手动发）
- **周一/三/五 20:30**：把本周赞最高的微头条扩写成首发长文
- **周日 20:10**：周复盘 + 更新题材权重 + 排下周选题

### 3. 运营台账（越跑越准）
维护一个 `运营台账.md`，记录：
- 人设档案（收入/房租/家庭细节，防穿帮）
- 已发选题（避免重复）
- 题材权重表（爆了加星，扑了降星）
- 本周数据记录（真实赞/阅读）

## 红线（必须遵守）

1. 每天最多1条，断更可以烂发不行
2. 标签≤3个，只从白名单选
3. 低流量旧内容不删不改，自然沉底
4. 不互赞互粉不买粉
5. 不虚构极端惨事（大病/被裁跳楼）
6. 不碰与内容无关的热点
7. 自动化只做到"出稿待发布"，绝不代用户点发布
