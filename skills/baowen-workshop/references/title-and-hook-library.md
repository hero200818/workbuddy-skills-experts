# 爆款标题与钩子库（官方公开课体系 + 实战拆解）

## 标题6公式（写标题时至少套一个）

| 公式 | 结构 | 周哥示例 |
|---|---|---|
| 痛点结果式 | 痛点+结果/改变 | 35岁被嫌老，我用这招保住了工作 |
| 反常识式 | 反常识观点+真相 | 月薪18k却存不下钱，问题不在房租 |
| 数字清单式 | 数字+方法+好处 | 发工资必做的3件事，我坚持了5年 |
| 身份共鸣式 | 人群标签+扎心现状 | 北漂第10年，月薪1万4的普通人 |
| 悬念提问式 | 提问+话只说一半 | 发工资到账14200，我为什么在楼下站了十分钟？ |
| 情绪+利益式 | 情绪词+具体好处 | 后悔太晚知道！这账算清楚我才不乱花钱 |

## 标题的7个心理缺口

标题不是概括内容，是制造缺口，让读者觉得"不看就亏"：
**怕错过、想省钱、要省时、被冒犯、被戳中、被揭秘、被代表**。
写完标题自查：上面占了几个？一个都不占就重写。

## 微头条三种钩子（开头57字内必须出现一种）

1. **好奇钩**：话只说一半，故意留白。"昨晚女朋友说了句话，我一晚上没睡着……"
2. **共鸣钩**：替一个群体说出心里话（身份认同）。"35岁还在租房的人，是不是就我一个？"
3. **吐槽钩**：吐槽一件不合理的事（不针对具体人）。"工资到账那天，我才算明白什么叫白领。"

## 情感类短内容结构（100多字也能爆）

```
第1句：立人设标签 + 抛核心情绪点
中间：一个具体细节（金额/对话/动作）
收尾：一句温柔/自嘲的观点，不教育读者
最后：AB选择题互动
```
> 关键：不用长，短平快结构清晰就够；情绪要具体——不写"我好惨"，写"拌面加蛋14块我犹豫了三秒"。

## 关键词布局（帮算法识别语义标签）

- 开头情绪词：没想到、彻底无语、说真的、一晃就……
- 中间细节词：具体地名/金额/时间（沙县、6楼、14200.36）
- 结尾互动词："你们呢？""换你你怎么选？"
