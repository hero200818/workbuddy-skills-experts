# 标题与开头公式库

> 标题决定打开率，开头决定完读率。这两处没有灵感也能写——用公式套，再往里填具体的东西。
> **硬约束：标题 ≤30 字（言序通道）。写作阶段就按 30 写。**

---

## 一、标题：三种主力句式

### 公式 A · 数字 + 反差 + 对撞

```
[具体数字/年龄/金额] + [一种怕] + [另一种怕] + [：补一句戳人的结论]
```

示例：
- `35岁怕优化，60岁怕负担：你笑"老登"的底气，还没轮到你`（29 字）
- `停车61分钟按2小时收费，多地改了：被多收的钱没人算过`
- `月薪8000，给爸妈报了3个旅行团：这届年轻人的孝顺在还债`

**为什么有效**：数字给可信度，两种处境给对撞，冒号后那句给情绪落点。
**注意**：数字必须是文中真有的数字，不能为了对仗编。

### 公式 B · 设问反思（把一个大家默认的事翻过来问）

```
[人人都会…/明明天天…] + [为什么还要…] + ？
```

示例：
- `人人都会变老，为什么要嘲笑"老登"？`
- `明明是我们点的外卖，为什么摆上婚宴就成了"寒酸席"？`
- `都说要省钱，为什么改个计费方式大家反而更愿意付？`

**为什么有效**：不指责读者，把矛头指向"默认规则"，读者敢转发。
**注意**：设问要有真答案。问完答不上来，就是标题党。

### 公式 C · 温情冲突（一个人 + 一个笨拙的动作）

```
那个[被我们怎么称呼的人]，可能正[笨拙地做什么]
```

示例：
- `那个被我们叫"老登"的人，可能正笨拙地爱着你`
- `那个在群里只发"收到"的人，可能刚学会用微信`

**为什么有效**：反差在"称呼"和"动作"之间，不需要形容词。
**注意**：不能滑向煽情。**必须有一个具体动作**，不能只有"爱着你"。

## 二、标题的 30 字节奏

30 字大约是一口气读完的长度，结构上分两截最稳：

| 结构 | 字数分配 | 例 |
|---|---|---|
| 前段铺事实 + 冒号 + 后段给判断 | 15 + 14 | `35岁怕优化，60岁怕负担：你笑"老登"的底气，还没轮到你` |
| 前段设问 + 逗号 + 后段递进 | 14 + 15 | `人人都会变老，为什么要嘲笑"老登"？`（更短，更利） |
| 一句话说完，靠破折号转 | 20 + 10 | `他被优化了三次——最后一次是在体检报告上` |

**过长的信号**：需要读两遍才懂 → 砍掉形容词，留动词和名词。

## 三、五类绝对不碰（会被限流/判定标题党）

1. 混淆官方口吻：「官方通报」「权威发布」「紧急通知」
2. 紧迫诱导：「速看」「看完即删」「再不看就晚了」「不看后悔」
3. 养生恐吓：「这东西千万别再吃了」「吃一口等于抽十根烟」
4. 明星隐私：「某某婚变内幕」「某某孩子生父曝光」
5. 对抗审核：空格拆字、生僻字、火星文、符号替代

## 四、开头钩子（前 3 行决定读者走不走）

**首段 ≤130 字。超过就该砍。**

### 钩子 1 · 场景切入（最稳，优先用）

直接给一个画面，不解释、不铺垫。

> 前两天在地铁上，一个五十来岁的男人给人让座，对方摆摆手说"不用不用"，他还是站起来了，扶着扶手，站了七站。

**要点**：有地点、有人、有一个多余的小动作。**那个小动作就是情绪。**

### 钩子 2 · 对话开场

第一句就是人说的话，带引号。

> "你们这儿招人，卡年龄吗？"
> 他问得很轻，像是怕听见答案。

**要点**：一句话 + 一个神态，不要写"他小心翼翼地问道"。

### 钩子 3 · 反常识断言

先扔一句和大众直觉相反的话，再用全文去证明它。

> 停车费按分钟算，停车场其实更赚钱。这不是我算的，是多地改了规则之后的结果。

**要点**：必须真的反常识，且后文必须给出证据。否则是标题党。

### 钩子 4 · 数字账单

把一件抽象的事摊成一笔账。

> 一小时零一分钟，收两小时的钱。北京一个车主算过，他一年在这上面多花了 480 块。

**要点**：数字要具体到个位，来源要能说清（"一个车主算过"也要真有其人或标明"网友计算"）。

### 钩子 5 · 自嘲暴露

先把自己放低，读者才愿意听。

> 我第一反应不是愤怒，是那种说不清的别扭——我居然也用过那个词。

**要点**：暴露的必须是真事，装出来的自嘲读者一眼看穿。

### 钩子 6 · 共识挑战

把一句人人都在说的话拎出来，然后问一句。

> "尊老爱幼"这四个字我们从小念到大，但没人教过：一个人从哪一岁开始，就值得被尊重了？

**要点**：挑战的是观念，不是人群。**不要指向某一代人**，那会变成对立。

## 五、结构骨架（三套，按选题类型选）

### 骨架 1 · 情绪递进五段（适合社会现象、年龄焦虑、亲情）

```
① 一个场景（≤130 字，画面切入）
② 一个数据或事实（给这件事一个公共维度）
③ 三层追问：为什么会这样 → 谁在受益 → 谁在承担
④ 一个反转或自省（把矛头从"他们"转向"我们"）
⑤ 一个具体问题收尾（引评论）
```

**关键**：第 ④ 段必须有。"都是他们的错"这种文章没人愿意转发，因为转发等于承认自己也是共谋；反过来，"我们都有份"才会有人留言。

### 骨架 2 · 账单拆解（适合收费、涨价、规则变化、被占便宜）

```
① 一笔具体的账（谁、多少钱、怎么算的）
② 规则是怎么变成这样的（历史 + 谁定的）
③ 有人改了吗，改成什么样（给一个已有解法）
④ 为什么改得动 / 改不动（利益结构）
⑤ 落到读者身上：你下次遇到该怎么办
```

**关键**：① 的账要算到读者能对照自己。第 ⑤ 段给可执行动作，不给口号。

### 骨架 3 · 对话还原（适合人际冲突、家庭关系、职场）

```
① 一句原话开场
② 还原现场：谁在场、什么表情、谁没说话
③ 换一个视角重讲一遍同一件事
④ 那句没人说出口的话是什么
⑤ 提问：你遇到过吗
```

**关键**：③ 的换视角是全文价值所在。同一件事讲两遍而不重复，靠的是换人。

## 六、结尾：只做一件事

**禁止**：「愿你我都能…」「希望每个人都被温柔以待」「让我们一起…」

**只做三选一**：

| 收法 | 写法 | 例 |
|---|---|---|
| 提问式 | 问一个**人人有故事**的具体问题 | 「你被叫过那个词吗？当时你在做什么？」 |
| 动作式 | 给一个下次能做的具体动作 | 「下次再听见那个词，你可以先不笑。」 |
| 大白话式 | 一句不带修饰的判断 | 「人都要老的。这句话不是安慰，是提醒。」 |

**判断标准**：读完结尾，读者脑子里有没有一句话想说？有，就成了。

## 七、配图与文字的关系

- 封面**不叠字**（AI 生成的中文基本是错的），标题交给平台编辑器
- 文中插画承担"换气"作用，放在段落最密的地方，不要放在小标题下
- 3–5 张即可。每多一张，完读率往下掉一点
- 图里不要有清晰人脸（隐私 + 版权双重风险）
