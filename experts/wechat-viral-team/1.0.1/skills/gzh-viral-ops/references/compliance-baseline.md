# 合规与创作基线

> 公众号写作的**唯一基线**。每次写稿前扫一眼，写完逐条划掉。
> 依据：微信《运营规范》4.1 / 4.9 / 4.10 / 4.11 / 4.12、《原创保护指引》3.6.1、
> 《标题党专项治理公告》(2024-05-30)、网信办《网络信息内容生态治理规定》
> 《互联网用户公众账号信息服务管理规定》。
> 可机检的部分已内置在 `rules/lint_rules.json`，由 `gzh.py lint` 执行。

## 一、内容红线（违反即删文/封号）

| 类别 | 条款 | 落地要求 |
|---|---|---|
| 涉政 / 外交 / 军事 | 4.12 | 一律不碰（台海、南海、军演、外国政要、民族宗教）。无新闻采编资质不得发时政新闻。 |
| 明星隐私爆料 | 4.1 | 不写私人生活、婚变、子女。**作品/剧集评论可以**。 |
| 未证实谣言 | 4.9 | 源头造谣可永久封号。宁可不写，也不赌"大概是真的"。转述必须交代来源并标明"未证实"。 |
| 侵权 / 隐私 | 4.1 | 不未经授权发他人原创内容；身份证号、手机号、可识别人脸照片一律打码或不用。 |
| 健康疗效 | 4.11.3 | **只写生活方式提醒，不下疗效断言**。禁止"治百病/根治/抗癌/排毒/降血压/增强免疫力"。 |
| 诱导分享 | 3.3 | 禁止"不转不是中国人""集赞抽奖""分享后继续看""看完记得转发"。**引导关注可以，诱导分享不行。** |
| 违规导流 | — | 正文不放站外二维码、微信号、私信领取、外部购买链接。 |
| 涉企侵权 | 清朗专项 | 企业负面必须基于权威信源、事实性引用；不捏造、不恶意贬损、不整篇搬运。 |
| 绝对化用语 | 广告法 | 禁用"最/第一/唯一/顶级/国家级/史无前例"，非广告文也尽量避开。 |
| 金融荐股 | 4.10 | 不写"必涨/抄底/稳赚"，不做个股买卖建议。 |

**判定原则**：拿不准的，不写。流量可以再找，号只有一条命。

## 二、标题规范

**硬约束**：≤30 字（走言序 API 的硬上限，超了发不进去）；微信原生编辑器可到 64 字。
👉 **写作阶段就按 30 字写。** 先写长再砍，钩子容易砍断。
👉 自检：`python scripts/gzh.py lint --md 稿子.md`

**禁止五类（标题党专项治理）**：

1. **混淆官方**：非官方却用"官方通报 / 权威发布 / 紧急通知"口吻。
2. **煽动蛊惑**：无依据夸大；"看完即删""速看""不看后悔""再不看就晚了"；惊悚恐吓。
3. **养生夸大**：绝对化、恐吓、以偏概全地说某食物某行为的好坏，煽动人"必须做/千万别做"。
4. **公众人物负面**：含糊表述造成混淆、蹭热点不交代清楚。
5. **对抗审核**：空格 / 生僻字 / 火星文 / 特殊符号规避；封面用"未读红点""虚假播放键"。

**加分方向**：数字 + 反差、设问反思、温情冲突。公式与例句见 `title-and-hook-library.md`。

## 三、原创声明（最易踩）

**"自己写的" ≠ 能标原创。**

不得声明原创的 10 类（3.6.1）中，最常撞上的五类：

- ② **公共公开内容**：法律法规、时事新闻、公开数据罗列
- ① **整合引用**：整篇搬运热搜/合集，必须有独家角度、结构或观点才算
- ③ **营销宣传内容**：广告不得标原创
- ⑤ **未获独家授权的再创造**：翻译、采访整理
- ⑥ **无意义堆字数**

**洗稿认定**：同义替换、语序调换、段落变换都算洗稿。有争议走"洗稿合议"，结果不支持申诉。
**转载**：必须走官方转载入口 + 原创方白名单授权，不能自己复制粘贴。

> 判断口诀：**这篇里有没有只属于你的东西？** 独家角度、独家采访、独家结构、独家数据。没有，就别勾原创。

## 四、账号调性（可改，但改了要全篇一致）

| 项 | 建议值 |
|---|---|
| 调性 | 轻量、口语、大众共鸣，像朋友唠嗑 |
| 人称 | 第二人称「你 / 咱们」为主 |
| 篇幅 | 1200–1800 字（长情绪文可到 2000） |
| 视角 | 普通人视角，不居高临下、不说教 |

**读者画像三条**：关心钱、关心工作、关心父母和自己的身体。凡不能落到这三件事上的选题，共鸣面撑不住。

## 五、去 AI 味清单（写完逐条划掉）

| 禁止 | 替换为 |
|---|---|
| 在这个…的时代 / 随着…的发展 | 直接进场景："前两天刷到个视频" |
| 不得不说 / 总而言之 / 众所周知 / 毋庸置疑 | 删掉，或"说白了" |
| 赋能 / 闭环 / 底层逻辑 / 抓手 / 颗粒度 / 组合拳 | 人话 |
| 三连排比（既是…也是…；不仅…更是…） | 全文留一处即够 |
| 抽象升华（"这就是人性的光辉"） | 一个具体动作或一句原话 |
| 每段都金句 | 让段落有长有短，允许废话和停顿 |
| 结尾"愿你我都能…" | 一个具体问题，或一句大白话 |
| 过度衔接（"接下来我们从三个维度来看"） | 直接讲下一件事 |

**加分项**：
- 方言感口语——"那股子客气里全是怕添麻烦"
- 具体数字——35 岁 / 60 岁 / 三遍 / 一分钟
- 有瑕疵的真实——"我第一反应也不是愤怒，是说不清的别扭"
- 对话原话——比任何形容词都有力

## 六、发布前自检清单

**脚本能查的**（`python scripts/gzh.py lint --md 稿子.md`）：

- [ ] 标题 ≤30 字（言序通道）、无紧迫诱导词、无对抗符号
- [ ] 无诱导分享话术、无疗效断言、无绝对化用语
- [ ] 无手机号 / 身份证号 / 正文外链
- [ ] 首段 ≤130 字、无 >160 字长段
- [ ] 结尾有具体问题（若以评论为 KPI）
- [ ] 配图 3–5 张

**只能人工查的**：

- [ ] 事实 / 信源：企业事件是否有权威来源？数字是否核对过？
- [ ] 是否整篇搬运热搜 / 合集（会被判非原创）
- [ ] 是否营销 / 广告性质（营销内容不得标原创）
- [ ] 涉政 / 明星隐私 / 未证实谣言 是否已剔除
- [ ] 配图是否自有 / 授权 / AI 生成（无版权隐患、无水印、无清晰人脸）
