# Content Matrix Studio · 内容矩阵专家团

一站式自媒体内容工厂：诊断账号、锁定人设、批量成稿、一键配图、复盘追爆，覆盖头条、小红书与微信公众号全链路。

## 类型

Team 型（多角色协作团队）

## 功能

由 14 个自建内容生产项目有机整合而成（v1.1 二期并入公众号线），五层流水线一个团队：

- **主理人 · 文枢（内容总编）**：意图路由、任务编排、质检汇编、成品交付
- **头条操盘手 · 闻达远**：账号诊断、爆款人设、100-150字微头条（实测106字最爆）、1200-1500字首发长文、评论话术、书影解读文 20篇/批
- **小红书操盘手 · 洪书意**：账号诊断、拉新/互动/人设三层选题、去模板化标题、6图笔记发布包
- **公众号操盘手 · 沈砚秋**：10w+ 爆款选题侦察、3000-5000字深度长文（刘润风格）、爆款封面设计、9张拆书卡片量产、Markdown 排版推送草稿箱
- **视觉设计总监 · 顾丹青**：Markdown 转四风格卡片图（极简长图/笔记本手账/iOS液态玻璃/头条号）、1080×1440 竖版图文、白描淡彩连环画、爆款封面、水印开放自定义
- **数据复盘师 · 秦镜明**：真实数据回收、五档阈值判定（爆款/小爆/正常/跑题/预警）、题材权重表、周复盘与下周排期

全团铁律：只出稿存草稿、发布权在用户手里；登录态过期即停；数据缺失写"未见数据"不编造；水印开放自定义不默认署名。

## 五条预设流水线

| 流水线 | 触发场景 | 产出 |
|-------|---------|------|
| W1 账号全链路激活 | 给账号要求诊断起号 | 诊断报告 + 人设档案 + 首周成稿7条 + 配图 + 排期 |
| W2 单篇/批量成稿出图 | 已有选题或文稿 | 成稿 + 按平台规格配图的发布包 |
| W2.5 公众号长文工厂 | 关键词/书单/原稿 | 选题清单 + 3000-5000字长文 + 封面/拆书卡片 + 草稿箱 |
| W3 数据复盘与追爆 | 提供数据/某条爆了 | 周复盘 + 追爆成稿/回退建议 + 题材权重表 + 下周排期 |
| W4 长文批量工厂 | 输入书/影/纪录片名 | 20 篇解读文 + 配图 + 全局目录 ZIP |

## 使用示例

- 诊断我的头条号，并出一周微头条排期
- 把这篇文章做成小红书6图笔记发布包
- 写一篇3000字公众号深度文，配封面并存草稿箱
- 把这本书拆成20篇头条解读文并配图
- 做本周复盘，这条爆了帮我追同结构

## 头像

头像已自动生成在 `avatars/` 目录下。如需替换为自定义头像，要求：
- 格式：PNG（推荐）或 JPG
- 尺寸：512×512 px
- 大小：单张不超过 500KB

## 安装

将专家包目录放到专家目录下：

```
C:\Users\Administrator\.workbuddy\plugins\marketplaces\my-experts\plugins/content-matrix-studio/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r content-matrix-studio.zip content-matrix-studio/
```
