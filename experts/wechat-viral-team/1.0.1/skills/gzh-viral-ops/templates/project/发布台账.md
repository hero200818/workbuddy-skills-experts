> 发布时间填实际推送时间；数据在发文后 24h / 72h 各回填一次。

## 发布前必查（每篇）

**一条命令搞定机器能查的**：

```bash
python scripts/gzh.py preflight --slug 选题N
```

它会确认：lint error=0 · 配图双档 · 封面存在 · 图片引用可解析 · bundle 比稿件新 · 台账已登记。
全绿后只剩人工项：

- [ ] 开原创声明、开留言
- [ ] 封面确认（是否要叠字）
- [ ] 自己先评论 1–2 条置顶
- [ ] 事实/信源人工复核（涉企事件是否有权威来源）
- [ ] 发完 24h / 72h 回填数据

## 复盘节奏

| 时点 | 动作 |
|---|---|
| 发布后 30 min | 回复前 5 条评论，制造"有人听"的氛围 |
| 24h | 回填阅读/评论/分享，判断开头钩子是否有效 |
| 72h | 回填完读率；完读率 <30% → 下一篇缩短首段、多拆段 |
| 每周日 | 汇总本周数据，跑 `retro` 看规律，校准选题评分 |
