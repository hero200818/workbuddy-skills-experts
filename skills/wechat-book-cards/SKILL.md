# 微信图文号 · 中国古典淡雅风拆书卡片

把一份书单（或畅销书周报）一键变成 **微信图文号 / 视频号图文** 可直接上传的拆书卡片：
- 9 张竖版图（1080×1350，4:5），正好卡满视频号图文 9 张上限；
- **封面与全部 8 张书卡统一为同一款「中国古典淡雅风」**，风格连续、品牌统一：
  - 宣纸暖米色渐变 + 淡月 + 淡墨远山（双层）+ 双线册页边框（外墨内朱）；
  - 标题用**华文楷体**、正文用**华文仿宋**，朱砂红印章点睛；
  - 封面与书卡共用同一 `classical_bg()`，视觉语言完全一致；
  - 封面与书卡均盖朱砂「書」藏书印，统一识别。
- 每卡结构：书名（楷体大字）→ 著者/分类 → 一句话推荐（朱线夹持引文）→ 拆书亮点×3（朱色序号 + 墨色正文）→ 金句（题跋式朱线夹持）→ 适合谁读 → 页脚。
- 旧版「iOS 玻璃拟态 / 9 套独立配色」主题已弃用（THEMES 保留备查但不再调用）。
- 附带可直接复制粘贴的**发布文案**（标题 + 描述 + 逐卡文字）。
- **微信图文号标题硬约束：发布标题必须 ≤20 字（中文/标点/数字均计 1 字）**。出文案时务必控制，宁可短而准，不要堆关键词。

## 何时使用
- 用户已有一份《全网畅销书周报》或任意书单，要变成可发布的图文号素材。
- 用户说"出拆书卡""做微信书单""把周报/书单做成卡片""生成读书图文号九宫格"。
- 用户要求"封面/书卡统一风格""做成中国古典风/国风"。

## 执行步骤

### 1. 准备书单数据
从乐享周报 / 用户给的 markdown / 用户口述中提取每本书的字段：
`书名、作者、分类、一句话推荐、3条拆书亮点、金句、适合谁读`。
- 封面固定展示本期书目清单（脚本自动生成）。
- 建议 8 本书（封面 1 + 书卡 8 = 9 张，刚好一期满图）。
- 书名过长（如《蛤蟆先生去看心理医生》）会自动换行；`file` 字段用短文件名（如 `蛤蟆先生`）。

### 2. 准备书单数据（两种模式）
**模式 A（推荐·自动化/批量用）：传入 books.json**
新建 `books.json`（UTF-8），结构：
```json
{
  "issue": "第44周",
  "date": "2026-10-26",
  "kind": "weekly",
  "books": [
    {"title":"书名", "file":"短文件名(无空格,长书名用缩写)",
     "author":"作者", "cat":"分类 · 子类",
     "rec":"一句话推荐(≤30字)",
     "points":["亮点1(≤45字)","亮点2(≤45字)","亮点3(≤45字)"],
     "quote":"金句(≤40字)",
     "who":"适合谁读(≤30字)"}
  ]
}
```
- `kind` 决定封面/文案的周期样式，三选一：`weekly`（周报，封面标"第XX周 · 日期"，页脚"每周一更新"）、`monthly`（月报，issue 形如"2026年10月"，页脚"每月初更新"）、`annual`（年报，issue 形如"2026年度"，页脚"每年初更新"）。不填默认 `weekly`。
- 书多于 8 本时：仅前 8 本生成书卡（封面+8=9 张，正好是视频号图文上限），封面会标"…等共 n 本好书"；`books` 可放 10~12 本做月度/年度盘点。
- `file` 用作图片文件名与封面短名（如《蛤蟆先生去看心理医生》用 `file:"蛤蟆先生"`）。
- （可选）`note`：如"数据未更新，本期沿用上期书单"，会在发布文案顶部标注。

**模式 B（手动改脚本）：直接编辑内置 `books` 列表**
打开技能目录下的 `gen_cards_ios.py`，在标注 `# 书籍数据` 的 `books` 列表中，按模板填入每本书：
```python
{"title":"书名", "file":"文件名(无空格)", "author":"作者", "cat":"分类 · 子类",
 "rec":"一句话推荐",
 "points":["亮点1","亮点2","亮点3"],
 "quote":"金句",
 "who":"适合谁读"}
```
**风格统一、保持连续性**：封面 `card_cover()` 与书卡 `card_book()` 都调用 `classical_bg()`，采用统一的「中国古典淡雅风」。**每期封面与书卡都长一样（只换周次/书目/内容）**，以建立品牌连续感，请勿随意改风格；如要调整，只改 `classical_bg()` 一处即可全局生效。

### 3. 运行生成器
用隔离环境里的 python（已装 Pillow；本机自带华文楷体/华文仿宋，缺则回退 simkai/simfang）：
```bash
VENV="$USERPROFILE/.workbuddy/binaries/python/envs/default/Scripts/python.exe"
# 模式 A：传 json + 期号 + 日期 + 输出基目录（按 期号 分子文件夹，不覆盖往期）
"$VENV" "<技能目录>/gen_cards_ios.py" "books.json" "第44周" "2026-10-26" "C:/.../畅销书拆书卡"
# 月度 / 年度同理，仅 json 里的 kind 与 期号 不同：
"$VENV" "<技能目录>/gen_cards_ios.py" "books.json" "2026年10月" "2026-10-31" "C:/.../畅销书拆书卡"
"$VENV" "<技能目录>/gen_cards_ios.py" "books.json" "2026年度" "2026-12-31" "C:/.../畅销书拆书卡"
# 模式 B：不传参，用脚本内置 books，输出到 畅销书拆书卡/第43周/（与自动化统一）
"$VENV" "<技能目录>/gen_cards_ios.py"
```
脚本会打印每本书"末笔 y"用于排查溢出（应 < 1180）；并在输出目录**自动清理本期不用的旧图**、**自动生成 `发布文案.md`**（含 3 个 ≤20 字标题 + 可粘贴描述 + 逐卡文字，标题与文案随 `kind` 自适应）。

### 4. 产出发布文案
脚本已自动写好 `发布文案.md`：3 个备选标题（**均 ≤20 字**，符合微信图文号标题限制）+ 一段可粘贴描述（含 `#话题标签` + 互动引导）+ 逐卡文字备份。直接复制使用即可，无需手改。

### 5. 展示结果
用 `present_files` 把 9 张 jpg（含 `发布文案.md`）一次性展示，提示上传顺序：封面→01→…→08。

## 设计约定（如需微调）
- 背景统一：`classical_bg()`（宣纸渐变 + 淡月 + 远山 + 双线框）。改风格只动这里。
- 印章：`_draw_seal()` 朱砂「書」印；想换字（如「读」「悦」）改调用处参数即可。
- 字体：华文楷体 `STKAITI.TTF`、华文仿宋 `STFANGSO.TTF`；缺失自动回退 `simkai.ttf`/`simfang.ttf`/`simsun.ttc`。
- 文字色：主墨 `INK_C (54,46,40)`、次 `SUB_C`、辅 `MUTE_C`、朱砂 `RED (150,42,36)`，模块级常量，改色只动一处。
- 尺寸：常量 `W,H = 1080,1350`；改尺寸需同步检查换行宽度 `CW`。

## 与"订阅自动化"联动（已接通 周/月/年 三套）
已建三套自动化，全部走本技能生成「中国古典淡雅风」拆书卡（9 张 + 发布文案），统一落盘到 `C:/Users/Administrator/WorkBuddy/畅销书拆书卡/期号/`：
- **每周订阅**「全网畅销书周报 + 拆书卡」：每周一 09:00，kind=weekly，目录 `第XX周/`。
- **每月订阅**「全网畅销书月报 + 拆书卡」：每月 1 日 09:00，kind=monthly，目录 `YYYY年M月/`。
- **每年订阅**「全网畅销书年报 + 拆书卡」：每年 1 月 1 日 09:00，kind=annual，目录 `YYYY年度/`。

三套均含**「数据未更新就沿用上期」的保险**：若 WebSearch 全部失败/无新数据，自动读取最近一期 `books.json`，改期号/日期并追加 `note`，照常出卡并在汇报中说明"沿用上期"。乐享周/月/年报写入同一知识库（space_id 6735d3d1992e4a70a91ecca428a0fbec）不同条目，按时间排序成订阅档案。

> 手动触发任一周期：先抓该周期榜单 → 写 `books.json`（含对应 `kind`）→ 跑上面模式 A 命令即可，结果同样进统一归档目录。
