# 文章质量自检清单

每篇文章生成后，逐项检查，不达标则修改后再输出。

## 一、标题检查（权重最高，影响点击率）

- [ ] 字数15-30字？
- [ ] 包含至少一个爆款元素（数字/悬念/冲突/反常识/情绪词）？
- [ ] 没有敏感词、绝对化用词（最、第一、唯一）？
- [ ] 不是标题党，正文内容能支撑标题？
- [ ] 手机端能完整显示？
- [ ] 目标读者看到会想点击？

## 二、开头检查（前200字决定读完率）

- [ ] 用了场景/悬念/冲突三种开头方式之一？
- [ ] 没有用"今天我们来聊聊"、"说到XX不得不提"等平淡开头？
- [ ] 开头出现了具体的人名、地名、时间或数字？
- [ ] 读完开头有"想继续看下去"的冲动？
- [ ] 开头不超过200字？

## 三、结构检查

- [ ] 有6-8个小标题（## 标记）？
- [ ] 小标题有悬念感或观点性，没有用"一、二、三"？
- [ ] 每个小标题下400-500字？
- [ ] 段落长度适中（手机阅读每段2-4句）？
- [ ] 整体逻辑清晰，有起承转合？

## 四、内容检查

- [ ] 每段都有信息量，没有注水？
- [ ] 有具体的细节（人名、对话、动作、数字、时间、地点）？
- [ ] 史实/观点准确，没有编造具体数据？
- [ ] 虚构作品分析时标注了"在剧中/在书里"？
- [ ] 有至少2-3个让读者"恍然大悟"或"深有同感"的点？
- [ ] 没有重复啰嗦的内容？

## 五、语言风格检查（去AI味核心）

- [ ] 没有"首先、其次、最后、综上所述、值得注意的是"等AI味表达？
- [ ] 没有"在历史的长河中、留下浓墨重彩的一笔"等套话？
- [ ] 用了短句，一句话不超过30字？
- [ ] 有口语化表达（说白了、有意思的是、你想想看）？
- [ ] 有反问句或感叹句？
- [ ] 像跟朋友聊天，不像写论文？
- [ ] 有个人观点和情绪，不是冷冰冰的陈述？

## 六、结尾检查（影响互动率）

- [ ] 没有简单总结全文？
- [ ] 用了升华或互动式结尾？
- [ ] 有引导评论的提问？
- [ ] 结尾控制在100字以内？
- [ ] 读完有余味，想评论或转发？

## 七、字数检查

- [ ] 全文2800-3500字？
- [ ] 如果少于2800字，补充了历史细节/人物对话/场景描写？
- [ ] 如果超过3500字，精简了重复分析/过渡段落？

## 八、头条号合规检查

- [ ] 没有政治敏感内容？
- [ ] 没有色情、暴力、低俗内容？
- [ ] 没有医疗/财经等需要资质的专业建议？
- [ ] 没有抄袭或大段引用他人内容？
- [ ] 标题和内容一致，不是标题党？
- [ ] 没有绝对化用词（最、第一、唯一，除非有依据）？

## 九、爆款元素检查

- [ ] 有至少1个"反常识"观点？
- [ ] 有至少1个"扎心/共鸣"的场景或句子？
- [ ] 有至少1个"干货/方法"可以收藏？
- [ ] 有至少1个"争议点"可以引发讨论？
- [ ] 有适合做封面图的场景或人物？

## 十、批量生成一致性检查

- [ ] 每篇切入角度不同，没有内容重复？
- [ ] 风格统一，但叙事节奏有变化？
- [ ] 标题风格统一但不雷同？
- [ ] 覆盖了规划的所有选题维度？
- [ ] 没有两篇文章用了相同的开头方式或结尾方式？

## 不合格修改指南

| 问题 | 修改方法 |
|------|----------|
| 标题平淡 | 套用headline-formulas.md中的10大公式重写 |
| 开头不抓人 | 改用场景/悬念/冲突开头，前200字必须出现具体细节 |
| AI味重 | 删除所有禁用表达，改用口语化表达，拆分长句 |
| 内容注水 | 删除重复分析，增加具体案例、数据、对话 |
| 字数不够 | 增加场景描写、人物心理、细节刻画 |
| 结尾平淡 | 加一个互动提问或金句升华 |
| 史实错误 | 重新检索核实，不确定的信息模糊化处理 |
