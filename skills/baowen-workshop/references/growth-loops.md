# 爆款增长飞轮（数据闭环 + 追爆机制）

## 一、周复盘必须读真数据，不做空想

每周日复盘时，用 browser 读后台：
- 打开 https://mp.toutiao.com/profile_v4/analysis/works-overall/all ，切"单篇"，读本周每条的展现/阅读/赞/评。
- 算出本周 Top1（赞最高或阅读最高）和最差的1条。
- 对照 references/proven-viral-cases.md 的爆款参数（106字、单切片、对话、身体反应、结尾提问），找出差距。
- 把结果写进运营台账"题材权重"：本周爆的题材加星，扑的降星。

## 二、判断阈值（来自账号历史数据）

| 信号 | 判定 | 动作 |
|---|---|---|
| 单条赞 >100 或阅读>1万 | 小爆款 | 当天追一条同结构、不同场景 |
| 单条赞 >300 或阅读>3万 | 爆款 | 2小时内回完评论；48小时内把它扩写成首发长文 |
| 连续3条赞<20 | 跑题 | 回到权重最高的已验证题材（人情世故/钱账） |
| 粉丝阅读占比仍<5% | 正常 | 公域拉新阶段，不焦虑 |
| 周掉粉>100 | 预警 | 检查是否碰红线/跑题 |

## 三、追爆SOP

爆款出现后24小时内：
1. **同结构追更**：换一个生活场景，复刻爆款的冲突-细节-提问结构（例：外卖撒了爆了→追一条外卖迟到/外卖小哥多送了水）。
2. **评论区挖选题**：高赞评论在讨论什么，下一条就写什么。
3. **长文承接**：爆点够强，48小时内按 article-playbook.md 扩写成1200-1500字首发长文。
4. **B轮联动**：把爆款故事的"父母辈/年代视角"改写一条粉丝向内容。

## 五、蹭平台话题扶持（免费流量）

消息中心会不定期发"话题邀请"（如 #某剧谁是内鬼#，503万人围观，带话题发文给流量扶持）。
- 日复盘时顺手打开 https://mp.toutiao.com/profile_v4/personal/message 看一眼。
- 凡是和我们粉丝口味搭的话题（民生、年代、社会情绪），当天那条微头条就带上该话题标签，蹭扶持。
- 追剧、明星、娱乐类话题不蹭，会打乱账号标签。

## 四、智能选题优先级

每天出稿前选题顺序：
1. 昨天评论区被问最多的问题（最高优先，已验证有共鸣）
2. 台账里本周加星的题材
3. 已验证四题材轮换（人情世故>钱账>外卖>职场）
4. 固定节点（发工资10号、交房租、过节随礼）
